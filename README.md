# Simple Interest Calculator

## Project Description
This project is a simple interest calculator written in Bash. It calculates simple interest based on the principal amount, annual interest rate, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Input
- Principal amount
- Annual rate of interest
- Time period in years

## Output
The calculated simple interest.

## Technologies Used
- Bash
- Shell Scripting
